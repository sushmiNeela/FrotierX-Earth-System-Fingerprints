# Project Overview

## Project

Earth System Fingerprints

## Challenge

NASA Space Apps Challenge 2026
Be An Earth System Trend Detective!

## Study Area

Bangladesh

## Core Variables

- Land Surface Temperature (LST)
- NDVI / Vegetation
- Soil Moisture

## Goal

The project aims to identify contrasting multi-variable environmental trends using NASA Earth observations.

## Planned Workflow

NASA Earth Observation Data
→ Quality Control
→ Temporal Aggregation
→ Common Spatial Grid
→ Trend Analysis
→ Statistical Significance
→ Multi-variable Fingerprint Detection
→ Interactive Visualization
